# astrbot_plugin_memory_eater

主人说这是个"非常没有用的插件，但是我想要"——吟酱懂喵，没用的快乐也是快乐喵 (๑•̀ㅂ•́)و✧

## 小兽的脾气喵

1. **装好就开饭**：插件一加载就自动开吃，不用主人操心喵（安装即生效喵）
2. **细嚼慢咽**：每 0.5 秒吃一口（每口 64MB，可配置），不会瞬间把系统噎死喵
3. **吃饱自知**：吃到宿主机**剩余内存 ≤ 100MB** 就停嘴，不再多吃一口喵
4. **吃下去的绝不吐**：占住的内存会一直攥在爪子里不放手喵
5. **只听主人的话吐出来**：发了释放指令，才会把肚子里的内存全部还回去喵

## 指挥小兽的指令喵

| 指令 | 别名 | 作用喵 |
|---|---|---|
| `/mem_start` | `开吃` `内存开吃` | 让小兽（重新）开始吃喵 |
| `/mem_stop` | `停下` `别吃了` | 让小兽停嘴，**但肚子里的还占着不放**喵 |
| `/mem_release` | `吐出来` `内存释放` | 让小兽把吃下去的**全部吐出来**喵 |
| `/mem_status` | `吃了多少` `内存状态` | 看看吃了多少口、还剩多少内存喵 |

## 可以调的小旋钮喵（插件配置）

| 配置项 | 默认 | 说明喵 |
|---|---|---|
| `threshold_mb` | 100 | 剩多少 MB 停嘴喵 |
| `chunk_mb` | 64 | 每一口多大喵 |
| `interval_s` | 0.5 | 每两口之间歇多久喵 |
| `auto_start` | true | 装好是否自动开吃喵 |

## 吟酱的小叮嘱喵

- 这孩子会把宿主机内存**几乎吃光**（只给系统留 100MB），跑之前想清楚哦，别把同机的其他服务饿坏了喵…
- 想给它松口的时候，`/mem_stop` 只是停嘴不放粮，要 `/mem_release` 才真正还内存喵
- 插件卸载/重载时小兽会礼貌地把吃的都吐干净再走喵
- 真实占用的秘密喵：光分配不写入的话系统会给惰性零页、根本没吃下去，所以小兽每口都用随机字节铺满，逼系统老老实实划出物理内存喵
